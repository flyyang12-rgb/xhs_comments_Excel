# 小红书笔记评论采集 Chrome 插件

当前版本：`v1.1.0`

## 安装

1. 打开 Chrome，进入 `chrome://extensions/`。
2. 开启右上角“开发者模式”。
3. 点击“加载已解压的扩展程序”。
4. 选择本目录：`xhs_chrome_extension`。

## 使用

1. 双击项目根目录的 `启动小红书签名服务.bat`，保持黑色窗口不要关闭。
2. 先在当前 Chrome 中打开并登录 `https://www.xiaohongshu.com/`。
3. 点击插件图标，根据需要选择一种模式：
   - **关键词采集**：输入关键词，例如 `儿童雨衣`，选择采集条数 `1-20`、排序方式、笔记类型和发布时间。
   - **笔记链接**：粘贴一条小红书笔记链接、xhslink 短链接，或包含链接的分享文字。
4. 点击“开始采集”。插件会自动读取当前 Chrome 的小红书登录态，获取笔记详情，并继续采集一级评论和二级评论。
5. 采集完成后点击“导出”，浏览器会下载：
   - `notes_raw.xlsx`
   - `comments_raw.xlsx`

## 说明

- 插件会自动读取当前 Chrome 的小红书 Cookie，并使用其中的 `a1` 生成签名。
- 签名逻辑使用本机 Node 服务执行，和 Spider_XHS 的 Node/execjs 思路一致；服务只负责生成请求头，不保存账号信息。
- 关键词搜索支持综合、最新、最多点赞、最多评论、最多收藏。排序值会直接写入搜索接口的 `sort` 参数。
- 支持“不限 / 图文 / 视频”笔记类型，以及“不限 / 一天内 / 一周内 / 半年内”发布时间。
- 链接模式一次采集一篇笔记，无效链接会在采集记录中提示。
- 点击“停止”后可选择采完当前笔记再停，或立即停止并保留已经采到的数据。
- 搜索请求使用当前 `/api/sns/web/v2/search/notes` 请求体；默认搜索不额外发送五组“不限”filters。
- 即使参数相同，网页与插件的结果仍可能因实时数据、个性化和灰度策略有少量差异。
- 如果出现安全限制、验证码或接口失败，插件会停止当前轮采集，已采集的数据仍可导出。
- 请求间隔默认 15 秒，可在弹窗中调大以降低风控概率。
