# 快速使用指南

## 第一次使用

1. 下载项目 ZIP，右键选择“全部解压”。不要直接在压缩包预览窗口中运行。
2. 进入解压后的文件夹，双击 `启动采集工具.bat`。
3. 首次运行会自动安装运行环境和所需组件。保持联网；弹出系统确认窗口时点击“是”或“允许”。
4. 安装完成后，脚本会自动打开 Chrome 扩展管理页和插件文件夹，并把插件路径复制到剪贴板。
5. 在 Chrome 开启右上角“开发者模式”，点击“加载已解压的扩展程序”。
6. 在选择文件夹窗口粘贴路径，选择 `xhs_chrome_extension` 文件夹。

首次安装完成后，以后只需双击 `启动采集工具.bat`。

## 开始采集

1. 双击项目根目录的 `启动采集工具.bat`，看到“启动成功”后保持窗口打开。
2. 在同一个 Chrome 中打开并登录小红书。
3. 点击扩展图标，输入关键词和采集数量。
4. 选择“最多评论”“最多点赞”或“最新”，开始采集。
5. 完成后分别导出 `notes_raw.xlsx` 和 `comments_raw.xlsx`。

建议首次只采集 1～3 条笔记，确认登录态、签名服务和 Excel 导出均正常后，再增加数量。

## 常见问题

- 自动安装失败：检查网络后重新双击启动文件；仍失败时按窗口提示安装 Node.js LTS。
- 提示所需组件安装失败：关闭窗口、检查网络，再重新双击启动文件。
- Windows 提示是否允许安装：点击“是”或“允许”。
- 提示未登录：在当前 Chrome 登录小红书后重试。
- 出现验证码、安全限制或接口错误：停止本轮采集，稍后再试并适当调大请求间隔。
- 插件更新后界面未变化：在 `chrome://extensions/` 中点击扩展的“重新加载”。
