# 快速使用指南

## 首次准备

1. 安装 [Node.js](https://nodejs.org/) 当前 LTS 版本。
2. 在 Chrome 地址栏打开 `chrome://extensions/`。
3. 开启“开发者模式”，点击“加载已解压的扩展程序”。
4. 选择项目中的 `xhs_chrome_extension` 文件夹。

## 开始采集

1. 双击项目根目录的 `启动采集工具.bat`，保持窗口打开。
2. 在同一个 Chrome 中打开并登录小红书。
3. 点击扩展图标，输入关键词和采集数量。
4. 选择“最多评论”“最多点赞”或“最新”，开始采集。
5. 完成后分别导出 `notes_raw.xlsx` 和 `comments_raw.xlsx`。

建议首次只采集 1～3 条笔记，确认登录态、签名服务和 Excel 导出均正常后，再增加数量。

## 常见问题

- 提示找不到 Node.js：安装 Node.js 后重新打开启动脚本。
- 提示未登录：在当前 Chrome 登录小红书后重试。
- 出现验证码、安全限制或接口错误：停止本轮采集，稍后再试并适当调大请求间隔。
- 插件更新后界面未变化：在 `chrome://extensions/` 中点击扩展的“重新加载”。
