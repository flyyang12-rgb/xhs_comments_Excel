# 小红书采集插件 1.2.0

按关键词或笔记链接采集公开笔记、一级评论和二级评论，导出 Excel。仓库仅提供插件 RAR 和本说明，已移除 Python 分析项目及其子模块配置。

**[下载插件 RAR](xhs_comments_Excel_repo.rar)**

## 安装

1. 使用 Windows 64 位电脑，下载并完整解压 RAR。
2. 双击 `启动采集工具.bat`，保持服务窗口打开。
3. 在 Chrome 打开 `chrome://extensions/`，开启“开发者模式”。
4. 点击“加载已解压的扩展程序”，选择包内的 `xhs_chrome_extension` 文件夹。
5. 在同一个 Chrome 中登录小红书，再打开插件。

已安装旧版时，先关闭旧服务，移除旧插件后加载新版，确认版本为 **1.2.0**。

## 使用

- **关键词采集**：输入关键词，设置笔记数量、排序；需要时设置笔记类型、发布时间。
- **笔记链接**：粘贴笔记链接或分享文字，开始采集。
- **采完当前笔记**：取得当前篇评论后停止。
- **立即停止**：停止后续采集，保留已取得的数据，当前篇可能不完整。

完成或停止后自动下载 `notes_raw.xlsx` 和 `comments_raw.xlsx`。建议先试 1～3 条笔记。

## 包内文件

| 文件或目录 | 用途 |
| --- | --- |
| `启动采集工具.bat` | 启动本机服务 |
| `xhs_chrome_extension` | Chrome 插件 |
| `service` | 必需的便携服务和运行组件 |
| `使用说明.txt`、`第三方说明.txt` | 使用步骤与来源说明 |

无需另外安装 Python、Node.js 或 Git。`service` 是插件的一部分，请保留整个目录。包内没有 Python 分析项目、开发脚本、Git 历史、个人 Cookie 和采集结果。

## 常见问题

- **服务端口被占用**：关闭旧签名服务窗口后重新启动。本版不能搭配旧签名服务。
- **登录已过期**：在当前 Chrome 重新登录小红书再试。
- **界面仍是旧版**：确认加载的是新解压目录，移除旧插件，重新加载新版。
- **验证码或访问限制**：停止采集，稍后重试；适当调大请求间隔。
