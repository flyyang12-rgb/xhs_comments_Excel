# 儿童大披肩防晒帽小红书舆情采集

本项目独立位于 `xhs_comments_Excel_py`，不会读取或修改旁边的 `xhs_comments_Excel_repo`。

## 使用方法

1. Windows 安装 Git、Python 3.10+、Node.js 20+。
2. 使用 `git clone --recurse-submodules https://github.com/flyyang12-rgb/xhs_comments_Excel_py.git` 下载完整项目。
3. 复制 `.env.example` 为 `.env`，填写 DeepSeek 和千问视觉 API 密钥。
4. 双击 `启动采集.bat`。
5. 首次运行等待独立环境安装完成。
6. 使用小红书 App 扫描终端二维码并确认登录。
7. 保持窗口开启，等待采集、AI 判断和 Excel 生成完成。

如果普通 `git clone` 后发现 `vendor/Spider_XHS` 为空，请在项目目录运行 `git submodule update --init --recursive`。

正常完成后，`output` 目录中只生成：

- `儿童大披肩防晒帽_差评.xlsx`
- `儿童大披肩防晒帽_好评.xlsx`

## 处理规则

- 采集关键词和正负向分析词统一在 `config.yaml` 管理，不需要修改 Python 源码。
- 每个关键词最多读取100条候选；差评、好评各自在链接去重后最多800条。
- 差评保留2024年1月1日及以后发布的笔记；好评保留采集日往前12个月；缺失或无法解析发布日期的笔记直接剔除。
- 好评仅保留近12个月，并按 `点赞 + 2×收藏 + 3×评论` 降序取前100条。
- 两个文件内部按规范化笔记链接去重；同一笔记只归入一个文件，同时存在明确负向问题时优先归为差评。
- 日期和基础字段筛选完成后才下载首张封面；图文只看首图，视频只看视频封面，不下载视频、不抽帧、不做OCR。
- 千问视觉模型按用户提供的正反例判断帽型：侧后方必须明显下垂遮挡耳部或后颈；只有前檐突出、普通宽檐帽或看不清的全部剔除，不设待复核。
- 通过封面审核后，DeepSeek使用标题、正文、标签识别品牌、广告、具体好评或差评、风险词和观点摘要；具体负向问题优先归为差评，纯提问不算好评。
- Excel 在“涉及产品”后单列“品牌名”，Kocotree、KK树等统一为“Kocotree（KK树）”。
- 本轮按全新规则重建两个Excel，不合并旧表数据。
- 不采集评论正文，不做图片 OCR。
- 遇到验证码、461或安全限制立即停止，不尝试绕过。

## 断点恢复

采集和 AI 判断的中间状态保存在 `_runtime/cache`。任务失败后重新双击同一个启动脚本，会尽量从断点继续；只有所有 AI 判断完成后才生成正式 Excel。

任务中断时保留搜索、详情、文字AI、视觉AI和封面缓存，可继续运行。两个Excel成功生成并通过表头、行数、链接校验后，程序自动删除封面图片，只保留紧凑JSON断点。
